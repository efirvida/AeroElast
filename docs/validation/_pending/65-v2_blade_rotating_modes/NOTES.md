## Differs, and why
- Mesh/properties: `build_v2_blade(0.25, skin_reference="mid")` instead of `BladeMesh(...)` + `build_rust_properties`.
  The helpers only read `RootNodes`, `node_id_to_index`, `mesh.nodes`, which the v2 builder provides.
- Test shape: v1 has one parametrized test collecting failures in a list. The store extractor reads only canonical
  `assert_relative_error(..., tol=, reference_name=, kind=)` calls, so v2 has two tests (parked, rated), three asserts each,
  one per family with a constant `reference_name`. All three families and their ElastoDyn comparisons are printed
  *before* the first assert (same evidence order as v1); the difference is that the first failing family stops the asserts of that
  test, whereas v1 reported every failing family in one message. Tolerance and bound are identical (`rel < tol`; v1 used `>=` to fail, same).
- Added `test_v2_s4_assembly_smoke` (non-slow, declared non-validation): builder + `MeshAssembler` + `assemble_k` + clamp set + span/orientation check.
- Rows are generated by `extract` (the v1 rows are hand-curated with `measured` stamps and adjudication text); the justification
  field reads "extracted from the code ... adjudicated in the pilot" and is **not** adjudicated.
