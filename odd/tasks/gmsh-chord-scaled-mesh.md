# gmsh blade mesh sized by the local chord (elements per chord instead of an element size)
Replace the uniform element size of the gmsh skin mesher by a size proportional to the local chord, so every section is discretised alike (thin tip sections get as many elements around as the root). Motivation: odd/tasks/gmsh-official-mesher.md L-S16..L-S35 (tip rows zig-zag, non-planar and strip-straddling rings, the 7 % ccx gap at the gmsh tip). Runner: scripts/aeroenv.sh; SLURM --ntasks only, not sequana_cpu_dev for long work.
