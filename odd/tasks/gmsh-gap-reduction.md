# gmsh mesh: identify and reduce the gap of the failing blade tests against their reference (IEA-15 first, then IEA-22)
The gmsh mesh is the only blade mesh in play (the v1 NuMAD mesh is out of scope). For every blade test that fails against its independent reference, find out whether the gap comes from the mesh, the shell model or the reference, and reduce what can be reduced without moving a tolerance. Follows odd/tasks/gmsh-store-campaign.md (L7, L8) and odd/tasks/gmsh-direct-physical-tests.md (VERDICT). Runner: scripts/aeroenv.sh; SLURM --ntasks only.

"Reduce" = a change in the model/mesh/extractor that moves the number toward the reference and that is justified independently of the reference, measured on the same command before and after.

## Shared-cause hypotheses (to separate, each with the experiment that kills it; none assumed)
- H1 shell model rather than mesh: F2, F4, F5 all show the shell more flexible than the beam in torsion/edge/flap by 3-10 % on sections whose FEM-free stiffness matches the deck. Test: a uniform section extracted from the blade, shell FEM vs closed-form thin-wall (Bredt-Batho torsion, EI) vs the same section as a BeamDyn beam.
- H2 mesh: element-size sensitivity of the failing quantity. Test: the quantity at 0.25 / 0.177 / 0.125 on the same code (already flat for F5: stable 0.5 pp 0.25 -> 0.125).
- H3 reference construction: the BeamDyn deck K is not the YAML section (PreComp homogenisation) for torsion and edge. Test: FEM-free thin-wall GJ and EI of the mesh against K44/K55/K66 band by band (done for EI: matches within 1 % in the IEA-22; the IEA-15 EImax band 0.87-0.95 at z 23-58 is unexplained).
