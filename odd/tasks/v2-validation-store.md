# v2 validation store

Extend the validation-matrix store (docs/validation/, tools/validation_matrix.py) with the windIO v2 counterpart of every blade test that exists for the v1 mesher. Prepared in parallel by independent groups; running the full campaign is a later step.

## Specs

- S1 "prepara la suite de store de la matriz de validacion para incluir los mismos tests que tenemos para la v1 con la v2"
- S2 "en paralelo porque son varios grupos de tests independientes que pueden implementarse en paralelo"
- S3 "luego volveremos a la validacion del framework" (earlier user line: v2 anchors stay a bounded side task; framework validation resumes afterwards, so prepare, do not run the whole campaign now)
- S4 Physics discipline of AGENTS.md applies: every row has a metric, an independent reference and a tolerance; no pass band is widened; mesh element size in [0.15, 0.25] m (the v2 mesher rejects others); report negative results.
- S5 Groups edit disjoint files; shared store files (groups.yaml, references.yaml, flags, residual patterns) are edited serially by the parent.
